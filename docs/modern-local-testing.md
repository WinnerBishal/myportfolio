# Modernization Local Testing

This repo now contains two parallel site implementations:

- Legacy Jekyll site in repository root
- Modern Astro site in `modern/`

## 1) Run Legacy Baseline (Jekyll)

From repo root:

```bash
bundle exec jekyll serve --port 4000
```

Open: http://localhost:4000

## 2) Run Modern Preview (Astro)

From repo root:

```bash
cd modern
npm run dev -- --port 4321
```

Open: http://localhost:4321

## 3) Production-like Preview for Modern Site

From `modern/`:

```bash
npm run build
npm run preview -- --port 4322
```

Open: http://localhost:4322
